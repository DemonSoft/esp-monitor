# Документация Esp Monitor

В этом каталоге собрана документация на русском языке для Esp Monitor — платформы для настройки, мониторинга и удаленного управления устройствами на базе ESP.

## Карта документации

- [Обзор продукта](overview.md) — назначение, возможности, архитектура и контекст для новичка
- [Быстрый старт](getting-started.md) — требования, установка, первый запуск и базовая работа
- [Руководство по прошивке](firmware.md) — поведение прошивки ESP, процесс настройки и MQTT-команды
- [Руководство по развертыванию](deployment.md) — локальная разработка и развертывание в Kubernetes

## Что дает проект

Esp Monitor помогает инженерам, установщикам и интеграторам работать с парком ESP-устройств более системно:

- выполнять первичную настройку Wi-Fi у новых устройств
- вести централизованный учет устройств и отслеживать их состояние
- передавать новые конфигурации удаленно через MQTT
- использовать базовые веб- и REST-интерфейсы управления
- вести журнал событий через Kafka при необходимости

## Рекомендуемый порядок чтения

1. Начните с [Обзор продукта](overview.md)
2. Затем прочитайте [Быстрый старт](getting-started.md)
3. При работе с устройствами обратитесь к [Руководству по прошивке](firmware.md)
4. Для настройки инфраструктуры используйте [Руководство по развертыванию](deployment.md)

## Примечания для новых пользователей

- Репозиторий включает как прошивку устройств, так и серверную часть.
- Сервер по умолчанию использует встроенную SQLite и в дальнейшем может быть расширен до PostgreSQL.
- MQTT и Kafka являются важной частью удаленного управления, но их можно подключать постепенно.
- Проект находится в активной разработке, поэтому часть функциональности может быть экспериментальной.
