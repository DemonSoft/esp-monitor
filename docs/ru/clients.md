# Руководство по клиентам и интеграции

## Компоненты клиентов в репозитории

В репозитории есть несколько клиентских ресурсов:

- примеры мобильного и настольного клиентов в каталоге clients
- вспомогательные скрипты и файлы развертывания
- примеры REST API, которые можно использовать из терминала или в собственных интеграциях

## Как система используется с точки зрения клиента

Клиент может взаимодействовать с Esp Monitor несколькими способами:

- через веб-интерфейс
- напрямую через REST API
- через загрузку или обновление списка устройств
- через просмотр состояния устройства и его конфигурации

## Важные аспекты интеграции

Если вы планируете подключать внешнее приложение к Esp Monitor, учитывайте следующее:

- для защищённых точек API нужен действительный X-Token
- API пока выглядит как лёгкий операционный интерфейс, а не как полностью стандартизированная внешняя платформа
- состояние устройств чаще всего распространяется через MQTT, а не только через REST
- Kafka полезен, если нужна потоковая обработка событий или аудит

## Рекомендуемый сценарий для новых интеграторов

1. начните с одного сервера и одного устройства
2. проверьте, что обновления состояния по MQTT видны
3. попробуйте простой вызов REST API для списка устройств
4. затем добавьте автоматизацию вокруг загрузки инвентаря или обновления конфигурации

## Примечания

Проект сейчас больше ориентирован на практическое управление устройствами, чем на готовые SDK или полностью стандартизированные клиентские библиотеки.
