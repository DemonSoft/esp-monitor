# Contributing to Esp Monitor

Thank you for your interest in contributing to Esp Monitor.

Contributions are welcome and appreciated. By participating in this project, you agree to follow these guidelines.

## Reporting Issues

Please include as much information as possible:

* software version;
* operating system;
* steps to reproduce the issue;
* expected behavior;
* actual behavior;
* logs or screenshots, if applicable.

## Pull Requests

Before submitting a pull request:

* create a dedicated branch;
* keep changes focused on a single purpose;
* update documentation when necessary;
* ensure the project builds successfully;
* verify that existing functionality is not broken.

## Coding Style

Please follow the existing coding style used throughout the project.

General principles:

* write clear and maintainable code;
* prefer simplicity over cleverness;
* avoid unnecessary dependencies;
* document exported APIs;
* keep functions small and focused.

## Commit Messages

Use concise and descriptive commit messages.

Examples:

* Add device discovery service
* Fix SQLite migration
* Improve HTTP error handling
* Update project documentation

## Licensing

By submitting code, documentation, or other contributions, you agree that your contribution is licensed under the terms of the Esp Monitor Community License (EMCL).

You also confirm that you have the right to submit the contributed work.

## Code of Conduct

Please be respectful and constructive in all discussions.

The goal is to build a friendly and professional community around Esp Monitor.
