# Esp Monitor

Esp Monitor is a client-server platform for discovering, provisioning, monitoring, and remotely managing ESP-based devices.

The project is designed primarily for installers, system integrators, and service engineers who deploy ESP devices into customer networks. It simplifies the initial configuration of devices, provides centralized monitoring, and enables secure remote management.

## Features

* Automatic discovery of ESP devices
* Initial Wi-Fi provisioning
* Remote device management
* Device status monitoring
* Secure client-server communication
* Cross-platform client applications
* REST API for integrations

## Project Structure

The project consists of several components:

* **Server** — central management service.
* **Desktop Client** — management application for installers and administrators.
* **Mobile Client** — simplified application for on-site configuration.
* **ESP Firmware** — firmware running on supported ESP devices.
